# Introducing OrchX

## What is OrchX

OrchX is DataGOL's agentic orchestration layer. Describe the outcome you want in plain English, and OrchX builds, runs and maintains the pipeline for you, from raw sources to dashboard-ready data, all on one platform.

It builds the semantic layer by creating pipelines and queries and allocating the infrastructure those pipelines need to run. It is an abstraction over both infrastructure and query code, so you work with outcomes instead of plumbing.

## Why OrchX

- **From request to running pipeline in one conversation.** No hand-offs between analysts, data engineers and infrastructure teams.
- **Fewer failed runs.** OrchX checks its assumptions on real data before it builds, so pipelines are far more likely to work the first time.
- **Less maintenance.** Self-healing handles routine failures, and every pipeline comes with lineage you can trace end to end.
- **One platform.** Sources, pipelines, layers, schedules and dashboards all live in DataGOL.

## Key capabilities

| Capability | What it does |
| --- | --- |
| **Natural language to pipeline** | One prompt becomes a running pipeline. OrchX finds the right sources, plans the DAG and writes the SQL. |
| **Connect and move any data** | Sync data sources, SaaS apps, files and APIs to any destination, on demand or on a schedule. |
| **Bronze, Silver, Gold layers** | Every pipeline is organized into raw, cleaned and business-ready layers, with end-to-end lineage built in. |
| **Review before it runs** | OrchX validates row counts, nulls and joins on sample data, then shows you the plan to approve. |
| **Self-healing pipelines** | Failures are retried, diagnosed and fixed automatically, before they reach your dashboards. |
| **Work with your files** | Upload documents directly to OrchX, and it reads and uses them throughout the entire workflow, even in long conversations. |
| **Schedules in your timezone** | Set up, confirm and review schedules in your own timezone. Ask for UTC whenever you need it. |

## How it works

OrchX takes you from a plain-English request to a running, monitored pipeline in six steps. You stay in control at every decision point.

1. **Describe the outcome.** Tell OrchX what data you need and where it should land, for example a daily revenue table by region ready for a dashboard.
2. **Answer a few setup questions.** If OrchX needs a detail, such as which data source, which tables or which destination, it asks one question at a time above the message box. You can pick an option, type your own answer or skip.
3. **Review the plan.** In Plan mode, OrchX writes a plan document covering sources, layers, transformations and schedule. Nothing is built until you approve it.
4. **Validate on sample data.** Before building, OrchX runs small, read-only checks to confirm columns exist, joins don't duplicate rows, filter values are spelled correctly and date ranges are available.
5. **Build and run.** In Build mode, OrchX creates the pipelines, writes the SQL, organizes the Bronze, Silver and Gold layers and allocates the resources to run them. You can see each step as it happens: the query being run, the table being targeted and how long it has taken.
6. **Monitor and self-heal.** Once live, pipelines run on demand or on schedule. Failures are retried, diagnosed and fixed automatically before they reach your dashboards.

## Built-in safeguards

OrchX is designed to act only on what you approve and to keep your data and credentials safe.

- **Plan first, build second.** Every session starts in Plan mode. Switching to Build is an explicit choice for that session only.
- **Approval before changes.** Creating, modifying, running or deleting a pipeline still requires your confirmation.
- **Read-only validation.** The sample-data checks OrchX runs are strictly read-only and limited to small samples. It never creates throwaway pipelines just to test a query.
- **Credentials stay out of chat.** Connection details are entered in a secure form, and any password is masked as "[redacted]" wherever it would otherwise be stored or shown.
- **Meaningful plans only.** A greeting or simple question never becomes a plan. OrchX updates your current plan instead of starting a competing one.

## Working with OrchX

The OrchX workspace is built for a fast back-and-forth with the agent.

- **Chat and workbench side by side.** Talk to OrchX on one side and see the workflow, plans and notes on the other. Plans open in a clean reading view, with editing one click away.
- **Visible agent activity.** Each running step shows what it is doing and for how long, so a long operation never looks stalled.
- **File attachments.** Attach documents and data files to give OrchX context. Attached files stay available for the whole conversation.
- **Plans and notes you control.** Edit or delete plans and notes in the side panel. Only you can delete a document.
- **Local-time scheduling.** OrchX asks, confirms and displays schedule times in your browser's timezone, while storing them in UTC behind the scenes.

## Availability

OrchX is available starting with DataGOL v1.0.351, released October 14, 2026.
