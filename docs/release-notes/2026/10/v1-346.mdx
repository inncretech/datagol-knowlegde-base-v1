## Enhancements

### AI
- **Cross-Document References in Knowledge Base Search:** Knowledge Base search can now find documents that are connected to each other, not just individual passages. While a document is indexed, DataGOL picks out the references it contains, such as industry standards (for example, ASTM D4541), DOIs, and links. When a search returns a document, other documents that cite the same reference are shown alongside it as related results. Agents can then point these out, for example "another document also references ASTM D4541," so users no longer have to search through folders by hand.
