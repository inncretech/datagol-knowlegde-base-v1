**Date released: October 13, 2026**


## Enhancements

### Security
- **Stronger Encryption for Stored Data:** The encryption DataGOL uses to protect sensitive stored data has been strengthened to a more secure mode, in line with current security standards.

## Bug Fixes

- Fixed an issue where D.A.V.E. could stall or report an unclear error when its own tool calls had missing or out-of-range details, such as a chart request missing its columns. D.A.V.E. now repairs these calls where it can, or gets a clear message about what's wrong so it can try again correctly.
