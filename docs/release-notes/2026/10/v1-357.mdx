## Enhancements

### AI Agents
- **Embed D.A.V.E. in Your Own Applications:** D.A.V.E. can now be embedded in third-party applications through an agent profile, so external users can analyze data in conversations without signing in to DataGOL. Each embed uses its own restricted account that can only view the workspaces in its profile. Every query is limited to the profile's workbooks and the embed session's filters, and a query is refused if those filters can't be applied. Signed-in embed users only see their own conversations.
