**Date released: October 2, 2026**


## Bug Fixes

- Fixed an issue where saving widgets from D.A.V.E. to a dashboard showed "[object Object]" instead of the actual error. The real reason, such as "Invalid access", now appears. When a user doesn't have permission for a workspace's dashboards, D.A.V.E. now tells them to ask a workspace owner or administrator for access instead of offering retries or workarounds that can't succeed. D.A.V.E. also no longer uses the internal term "scope" in its replies and refers to "selected for this chat" instead.
