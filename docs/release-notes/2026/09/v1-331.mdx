**Date released: September 9, 2026**


## Enhancements

### AI Agents
- **New Gemini Model Available:** A new Google Gemini model has been added to the list of models available for DataGOL's AI features.

## Bug Fixes

- Fixed an issue where embedded dashboards and pages used the viewer's browser timezone even when the Timezone feature was turned off for the embed. This made the same dashboard show different values for viewers in different locations, and scheduled PDF reports didn't match the live view. With the feature off, embeds now consistently use UTC, and scheduled PDFs match what viewers see.
