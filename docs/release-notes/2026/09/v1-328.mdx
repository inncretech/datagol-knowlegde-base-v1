**Date released: September 3, 2026**


## Enhancements

### AI Agents
- **Bring Your Own Azure OpenAI:** Account admins can now save their company's Azure OpenAI API base URL and API key in DataGOL, alongside the existing OpenAI, Anthropic, Gemini, Vertex AI, and Bedrock keys. Once saved, the company's Azure deployment is registered so DataGOL agents can route requests to it. The key is masked when viewed and can be removed at any time.
