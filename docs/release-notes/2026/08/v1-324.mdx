**Date released: August 28, 2026**


## Enhancements

### AI Agents
- **Clearer Agent Error Messages and Faster DAVE SQL Queries:** When an agent response fails, users now see a specific, actionable reason instead of a generic "Something went wrong" message. The same applies to chart failures such as timeouts or rejected queries. DAVE now works out the SQL dialect once per session when a single workbook is selected, which cuts repeated lookups and speeds up answers. Agents also show which engine each query ran on, and widgets now read from the correct data source.
