**Date released: August 20, 2026**


## Enhancements

### AI
- **Pinned Agent Management:** Introduced a limit of 5 pinned agents per user along with a dedicated management view, keeping pinned agents curated instead of growing into an unmanageable list.
<ImagePopup src="/img/release_notes/2026/2026/August/pinned-agents.png" alt="Pinned agents" caption="Pinned agents" />
- **Set a Default Agent from Explore:** Users can now set a default agent from Agents Explore so it appears on the home page automatically, without extra navigation.
<ImagePopup src="/img/release_notes/2026/2026/August/default-agents.png" alt="default agents" caption="default agents" />


## Bug Fixes

- Fixed an issue where opening a project link in AppX was noticeably slow and the chat scrollbar was positioned away from the chat box it belonged to. Page load time was improved and the scrollbar was repositioned to sit next to the chat box.
